## Context

This story implements the document upload pipeline - the first step in the user's workflow. Files must be uploaded to Supabase Storage and metadata saved to the database with exact schema matching frontend expectations.

**Critical Integration**: Frontend (`upload-store.ts`) expects specific response format and database fields. Any mismatch will break the UI.

## Critical Requirements

### Response Format (Frontend Contract)
**Frontend Expectation** (`docs/FRONTEND_BACKEND_GAP_ANALYSIS.md` Section 3.1):

```typescript
{
  id: string;           // UUID from documents table
  file_name: string;    // Generated filename
  original_name: string;
  status: string;       // 'uploaded'
  storage_path: string;
  page_count: number;
  file_size: number;
  message?: string;
}
```

**Database Schema Match** (CRITICAL):
- `file_name` - Generated filename (timestamp-based)
- `original_name` - User's original filename
- `storage_path` - Supabase Storage path
- `file_size` - Size in bytes
- `file_hash` - SHA-256 hash
- `page_count` - Extracted via PyPDF2
- `status` - Always 'uploaded' after successful upload

## Technical Implementation

### Step 1: Create Supabase Storage Bucket

**Via Supabase Dashboard**:
1. Go to Storage → Create bucket
2. Bucket name: `documents`
3. Public: **No** (private)
4. File size limit: 500MB

**Via SQL**:
```sql
-- Create bucket
INSERT INTO storage.buckets (id, name, public)
VALUES ('documents', 'documents', false);
```

**Configure RLS Policies** (for later when auth is added):
```sql
-- Storage policy: Users can upload to their tenant folder
CREATE POLICY "Users can upload to own tenant folder"
ON storage.objects FOR INSERT
WITH CHECK (
  bucket_id = 'documents'
  AND (storage.foldername(name))[1] = auth.jwt() ->> 'tenant_id'
);

-- Storage policy: Users can read their tenant's files
CREATE POLICY "Users can read own tenant files"
ON storage.objects FOR SELECT
USING (
  bucket_id = 'documents'
  AND (storage.foldername(name))[1] = auth.jwt() ->> 'tenant_id'
);
```

**For MVP (No Auth)**: Temporarily disable RLS on storage bucket:
```sql
ALTER TABLE storage.objects DISABLE ROW LEVEL SECURITY;
```

### Step 2: Implement Upload Endpoint

**File**: `backend/api/routers/documents.py`

```python
from fastapi import APIRouter, UploadFile, File, Query, HTTPException
from supabase import create_client
import hashlib
from datetime import datetime
import os
from PyPDF2 import PdfReader
import io
from typing import Optional

router = APIRouter(prefix="/api/documents", tags=["documents"])

# Initialize Supabase client
supabase = create_client(
    os.getenv("SUPABASE_URL"),
    os.getenv("SUPABASE_SERVICE_KEY")
)

@router.post("/upload")
async def upload_document(
    file: UploadFile = File(...),
    source_language: str = Query(default="en"),
    target_language: Optional[str] = Query(default=None),
    tenant_id: Optional[str] = Query(default=None)
):
    """
    Upload PDF to Supabase Storage and create document record

    Args:
        file: PDF file to upload
        source_language: Source language (ISO 639-1 code)
        target_language: Target language (optional)
        tenant_id: Tenant ID (auto-generated if not provided)

    Returns:
        Document metadata including ID, storage path, and page count
    """

    # ========================================================================
    # STEP 1: Validate File Type
    # ========================================================================
    if file.content_type != "application/pdf":
        raise HTTPException(
            status_code=400,
            detail="Invalid file type. Only PDF files are supported."
        )

    # ========================================================================
    # STEP 2: Read File Content
    # ========================================================================
    content = await file.read()
    file_size = len(content)

    # Validate file size (500MB max)
    MAX_FILE_SIZE = 500 * 1024 * 1024  # 500MB
    if file_size > MAX_FILE_SIZE:
        raise HTTPException(
            status_code=413,
            detail="File size exceeds maximum limit of 500MB"
        )

    # ========================================================================
    # STEP 3: Calculate SHA-256 Hash (Deduplication)
    # ========================================================================
    file_hash = hashlib.sha256(content).hexdigest()

    # Check for duplicate
    existing = supabase.table("documents").select("id, file_name, storage_path").eq("file_hash", file_hash).execute()

    if existing.data:
        # File already exists
        doc = existing.data[0]
        return {
            "id": doc["id"],
            "file_name": doc["file_name"],
            "storage_path": doc["storage_path"],
            "status": "duplicate",
            "message": "Document already exists (duplicate detected)"
        }

    # ========================================================================
    # STEP 4: Extract Page Count
    # ========================================================================
    try:
        pdf_reader = PdfReader(io.BytesIO(content))
        page_count = len(pdf_reader.pages)
    except Exception as e:
        raise HTTPException(
            status_code=400,
            detail=f"Failed to read PDF file: {str(e)}"
        )

    # ========================================================================
    # STEP 5: Generate Filename and Storage Path
    # ========================================================================
    timestamp = int(datetime.now().timestamp() * 1000)
    file_name = f"{timestamp}-{file.filename}"
    file_extension = os.path.splitext(file.filename)[1]

    # Generate tenant_id if not provided
    if not tenant_id:
        import uuid
        tenant_id = str(uuid.uuid4())

    storage_path = f"{tenant_id}/{file_name}"

    # ========================================================================
    # STEP 6: Upload to Supabase Storage
    # ========================================================================
    try:
        supabase.storage.from_("documents").upload(
            storage_path,
            content,
            file_options={"content-type": "application/pdf"}
        )
    except Exception as e:
        raise HTTPException(
            status_code=500,
            detail=f"Failed to upload file to storage: {str(e)}"
        )

    # ========================================================================
    # STEP 7: Create Database Record
    # ========================================================================
    document_data = {
        "file_name": file_name,
        "original_name": file.filename,
        "file_extension": file_extension,
        "mime_type": file.content_type,
        "file_size": file_size,
        "file_hash": file_hash,
        "storage_path": storage_path,
        "page_count": page_count,
        "status": "uploaded",
        "tenant_id": tenant_id,
        "user_id": "anonymous-user",  # TODO: Replace with actual user_id after auth
        "source_language": source_language,
        "target_language": target_language
    }

    try:
        result = supabase.table("documents").insert(document_data).execute()
        doc = result.data[0]
    except Exception as e:
        # Rollback: Delete file from storage
        supabase.storage.from_("documents").remove([storage_path])
        raise HTTPException(
            status_code=500,
            detail=f"Failed to create database record: {str(e)}"
        )

    # ========================================================================
    # STEP 8: Return Response
    # ========================================================================
    return {
        "id": doc["id"],
        "file_name": doc["file_name"],
        "original_name": doc["original_name"],
        "status": doc["status"],
        "storage_path": doc["storage_path"],
        "page_count": doc["page_count"],
        "file_size": doc["file_size"],
        "message": "Document uploaded successfully"
    }
```

```python
import pytest
from fastapi.testclient import TestClient
from api.main import app
import io

client = TestClient(app)

def test_upload_valid_pdf():
    """Test successful PDF upload"""
    # Create mock PDF
    pdf_content = b"%PDF-1.4\ntest content"
    files = {"file": ("test.pdf", io.BytesIO(pdf_content), "application/pdf")}

    response = client.post(
        "/api/documents/upload?source_language=en",
        files=files
    )

    assert response.status_code == 200
    data = response.json()
    assert "id" in data
    assert data["status"] == "uploaded"
    assert "page_count" in data

def test_upload_invalid_file_type():
    """Test rejection of non-PDF files"""
    files = {"file": ("test.txt", io.BytesIO(b"test"), "text/plain")}

    response = client.post("/api/documents/upload", files=files)

    assert response.status_code == 400
    assert "Invalid file type" in response.json()["detail"]

def test_upload_duplicate_file():
    """Test duplicate file detection"""
    pdf_content = b"%PDF-1.4\ntest content"
    files = {"file": ("test.pdf", io.BytesIO(pdf_content), "application/pdf")}

    # First upload
    response1 = client.post("/api/documents/upload", files=files)
    assert response1.status_code == 200

    # Duplicate upload
    files = {"file": ("test.pdf", io.BytesIO(pdf_content), "application/pdf")}
    response2 = client.post("/api/documents/upload", files=files)

    assert response2.status_code == 200
    data = response2.json()
    assert data["status"] == "duplicate"
```
