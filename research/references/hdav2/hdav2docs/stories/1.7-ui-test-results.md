**Component:** Queue Page - List View
**Issue:** On mobile devices (375px width), the list view table was not visible/scrollable.

**Solution Implemented:**

- Added navigation support - tapping completed cards opens editor

- Added click handlers with navigation to editor for completed tasks

**Status:** ✅ **RESOLVED**
