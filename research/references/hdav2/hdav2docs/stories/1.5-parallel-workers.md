## Critical Requirements

### 1. pgmq Concurrency Model

**How pgmq Handles Concurrency**:
- pgmq provides **message visibility timeout** (VT)
- When Worker A reads a message, it's invisible to other workers for VT seconds
- If Worker A doesn't archive/delete the message within VT, it returns to the queue
- **ACID guarantees**: No two workers can read the same message simultaneously

**What This Means**:
```python
# Worker 1
msg = pgmq.read('text_extraction_queue', vt=300)  # Message invisible for 5 min

# Worker 2 (at same time)
msg2 = pgmq.read('text_extraction_queue', vt=300)  # Gets DIFFERENT message

# If Worker 1 crashes, message automatically returns after 300 seconds
```

**No Code Changes Needed**: Current worker code is already concurrency-safe! Just run multiple instances.

### 3. Worker Pool Manager Architecture

**Simple Multiprocessing Approach**:
```
WorkerPoolManager (parent process)
    │
    ├─── Worker Process 1 (worker_id=0)
    ├─── Worker Process 2 (worker_id=1)
    ├─── Worker Process 3 (worker_id=2)
    └─── Worker Process 4 (worker_id=3)

Each worker:
- Independent process (not thread - GIL avoidance)
- Own memory space
- Own database connections
- Polls pgmq independently
```

**Why Multiprocessing (not Threading)**:
- Python GIL limits threading for CPU-bound work
- Processes = true parallelism
- Process crashes don't affect others
- Easier to monitor (separate PIDs)

### Step 2: Create Worker Pool Manager

**File**: `backend/workers/worker_pool_manager.py` (NEW)

```python
import multiprocessing as mp
import os
import signal
import time
from typing import List, Dict
from datetime import datetime
from dotenv import load_dotenv

load_dotenv()


class WorkerPoolManager:
    """
    Manages a pool of text extraction worker processes

    Features:
    - Spawns N worker processes
    - Health monitoring
    - Graceful shutdown
    - Auto-restart on failure
    """

    def __init__(self, pool_size: int = 4):
        self.pool_size = pool_size
        self.workers: List[Dict] = []
        self.shutdown_flag = False

        # Register signal handlers
        signal.signal(signal.SIGTERM, self._handle_shutdown)
        signal.signal(signal.SIGINT, self._handle_shutdown)

    def start(self):
        """Start the worker pool"""
        print(f"🚀 Worker Pool Manager starting with {self.pool_size} workers")
        print(f"   Manager PID: {os.getpid()}")
        print(f"   Queue: text_extraction_queue")
        print("-" * 60)

        # Spawn worker processes
        for i in range(self.pool_size):
            self._spawn_worker(i)

        print(f"✅ {self.pool_size} workers started successfully")
        print()

        # Monitor loop
        self._monitor_workers()

    def _spawn_worker(self, worker_id: int):
        """Spawn a single worker process"""
        process = mp.Process(
            target=self._run_worker,
            args=(worker_id,),
            name=f"TextExtractionWorker-{worker_id}"
        )
        process.start()

        worker_info = {
            'worker_id': worker_id,
            'process': process,
            'pid': process.pid,
            'started_at': datetime.now(),
            'restart_count': 0
        }
        self.workers.append(worker_info)

        print(f"   Worker-{worker_id} spawned (PID: {process.pid})")

    def _run_worker(self, worker_id: int):
        """
        Target function for worker process
        Imports and runs TextExtractionWorker
        """
        try:
            # Import here to avoid pickling issues
            from text_extraction_worker import TextExtractionWorker
            import asyncio

            worker = TextExtractionWorker(worker_id=worker_id)
            asyncio.run(worker.run())

        except KeyboardInterrupt:
            print(f"[Worker-{worker_id}] Received shutdown signal")
        except Exception as e:
            print(f"[Worker-{worker_id}] Fatal error: {e}")
            raise

    def _monitor_workers(self):
        """
        Monitor worker health and restart if needed
        Runs until shutdown signal received
        """
        print("📊 Monitoring worker health...")
        print("   Press Ctrl+C to shutdown gracefully")
        print()

        while not self.shutdown_flag:
            time.sleep(10)  # Check every 10 seconds

            # Check each worker
            for worker_info in self.workers:
                process = worker_info['process']
                worker_id = worker_info['worker_id']

                if not process.is_alive():
                    print(f"⚠️  Worker-{worker_id} died (PID: {worker_info['pid']})")

                    # Auto-restart if not shutting down
                    if not self.shutdown_flag:
                        print(f"🔄 Restarting Worker-{worker_id}...")
                        self.workers.remove(worker_info)
                        self._spawn_worker(worker_id)
                        self.workers[-1]['restart_count'] = worker_info['restart_count'] + 1
                        print(f"✅ Worker-{worker_id} restarted (restart #{self.workers[-1]['restart_count']})")

    def _handle_shutdown(self, signum, frame):
        """Handle graceful shutdown on SIGTERM/SIGINT"""
        print()
        print("🛑 Shutdown signal received")
        print("   Stopping workers gracefully...")
        self.shutdown_flag = True

        # Terminate all workers
        for worker_info in self.workers:
            process = worker_info['process']
            worker_id = worker_info['worker_id']

            if process.is_alive():
                print(f"   Stopping Worker-{worker_id} (PID: {worker_info['pid']})")
                process.terminate()
                process.join(timeout=5)

                # Force kill if still alive
                if process.is_alive():
                    print(f"   Force killing Worker-{worker_id}")
                    process.kill()
                    process.join()

        print("✅ All workers stopped")
        print("👋 Worker Pool Manager shutdown complete")

    def get_status(self) -> Dict:
        """Get worker pool status for API endpoint"""
        active_workers = sum(1 for w in self.workers if w['process'].is_alive())

        return {
            'pool_size': self.pool_size,
            'active_workers': active_workers,
            'workers': [
                {
                    'worker_id': w['worker_id'],
                    'pid': w['pid'],
                    'alive': w['process'].is_alive(),
                    'started_at': w['started_at'].isoformat(),
                    'restart_count': w['restart_count']
                }
                for w in self.workers
            ]
        }


# Run worker pool
if __name__ == "__main__":
    # Get pool size from environment (default: 4)
    pool_size = int(os.getenv("WORKER_POOL_SIZE", "4"))

    manager = WorkerPoolManager(pool_size=pool_size)
    manager.start()
```

### Step 3: Add Worker Status API Endpoints

**File**: `backend/api/routers/workers.py` (NEW)

```python
from fastapi import APIRouter, HTTPException
import psycopg2
import os
from typing import Dict

router = APIRouter(prefix="/api/workers", tags=["workers"])


@router.get("/status")
async def get_worker_status() -> Dict:
    """
    Get worker pool status

    Returns:
        Worker count, active jobs, queue depth
    """
    try:
        # Connect to database
        conn = psycopg2.connect(os.getenv("DATABASE_URL"))
        cursor = conn.cursor()

        # Get queue depth
        cursor.execute("""
            SELECT COUNT(*)
            FROM pgmq.text_extraction_queue;
        """)
        queue_depth = cursor.fetchone()[0]

        # Get active jobs (processing status)
        cursor.execute("""
            SELECT COUNT(*)
            FROM text_extraction_results
            WHERE status = 'processing';
        """)
        active_jobs = cursor.fetchone()[0]

        # Get completed jobs (today)
        cursor.execute("""
            SELECT COUNT(*)
            FROM text_extraction_results
            WHERE status = 'completed'
            AND created_at::date = CURRENT_DATE;
        """)
        completed_today = cursor.fetchone()[0]

        cursor.close()
        conn.close()

        # Note: Worker count is static (configured via WORKER_POOL_SIZE env var)
        # In production, this could query a shared state or monitoring service
        worker_pool_size = int(os.getenv("WORKER_POOL_SIZE", "4"))

        return {
            "worker_pool_size": worker_pool_size,
            "active_jobs": active_jobs,
            "queue_depth": queue_depth,
            "completed_today": completed_today,
            "status": "healthy" if active_jobs <= worker_pool_size else "busy"
        }

    except Exception as e:
        raise HTTPException(status_code=500, detail=str(e))


@router.get("/health")
async def health_check() -> Dict:
    """
    Health check endpoint for monitoring

    Returns:
        Health status of worker pool
    """
    try:
        # Test database connection
        conn = psycopg2.connect(os.getenv("DATABASE_URL"))
        cursor = conn.cursor()
        cursor.execute("SELECT 1;")
        cursor.close()
        conn.close()

        # Test pgmq queue exists
        conn = psycopg2.connect(os.getenv("DATABASE_URL"))
        cursor = conn.cursor()
        cursor.execute("""
            SELECT COUNT(*)
            FROM pgmq.text_extraction_queue;
        """)
        cursor.close()
        conn.close()

        return {
            "status": "healthy",
            "database": "connected",
            "queue": "available"
        }

    except Exception as e:
        raise HTTPException(
            status_code=503,
            detail=f"Worker pool unhealthy: {str(e)}"
        )
```

## ✅ COMPLETION SUMMARY (2025-10-03 20:40 IST)

### Implementation Approach: Single-Process Async Pool

**Architecture Decision**: Pivoted from multiprocessing to asyncio after encountering Windows compatibility issues.

**Original Plan**: Python `multiprocessing.Process` with 4 separate worker processes
**Issue Encountered**: `TypeError: cannot pickle 'weakref.ReferenceType' object` on Windows Python 3.13
**Root Cause**: Windows uses `spawn` method (not `fork`), requiring all objects to be pickled. Signal handlers created weakref objects that couldn't be pickled.
**Final Solution**: Single-process async pool with 4 concurrent coroutines using `asyncio`

### Files Created

1. **`backend/workers/worker_pool.py`** - Single-process async worker pool (FINAL SOLUTION)
   - `AsyncWorkerPool` class with configurable pool size
   - 4 concurrent async workers (coroutines)
   - Each worker polls queue independently using `asyncio.sleep()`
   - Shared database connection for queue polling
   - Individual Supabase clients and Vertex AI services per worker
   - Graceful shutdown on KeyboardInterrupt

2. **`backend/api/routers/workers.py`** - Worker status API endpoints
   - `GET /api/workers/status` - Returns pool size, active jobs, queue depth, utilization
   - `GET /api/workers/health` - Health check endpoint

### Benefits of Async Approach

1. **No pickle issues** - All objects stay in same process
2. **Simpler architecture** - Single process easier to manage than multiprocessing
3. **Less overhead** - No inter-process communication needed
4. **Easier debugging** - All logs in one process
5. **Windows compatible** - No fork/spawn complications
6. **Production ready** - Equally effective as multiprocessing for I/O-bound tasks
