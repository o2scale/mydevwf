## Known Issues

### Issue 1: Extraction Already Exists Error
**Description**: Uploading the same file returns existing document ID, but extraction fails with "Text already extracted"

**Root Cause**: Duplicate detection on upload, but extraction endpoint doesn't allow re-extraction

**Impact**: Medium - Cannot reprocess same document

**Workaround**: Upload file with different name

**Fix Required**: Implement re-extract endpoint or add `force` parameter

---

### Issue 2: Processing Time Estimation Inaccurate
**Description**: Estimated time (20s for 10 pages) vs actual time (45s)

**Root Cause**: Doesn't account for Vertex AI network latency

**Impact**: Low - Just an estimate, users see real progress

**Fix Required**: Update estimation formula to 5-10s per page
