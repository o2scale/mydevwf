## Critical Integration Points

From `FRONTEND_BACKEND_GAP_ANALYSIS.md` Section 9.2:

| Step | Integration Point | Requirement |
|------|------------------|-------------|
| Upload | File validation | Only accept `application/pdf` MIME type |
| Database | Schema match | Exact field names: `file_name`, `original_name`, `storage_path` |
| Batching | Token estimation | Use algorithm from TECHNICAL_ARCHITECTURE.md Section 7.1 |
| Vertex AI | API limits | Handle 1M token limit, implement retry logic |
| **Page Markers** | **Format match** | **CRITICAL**: Use exact format `# [Page N]` |
| Realtime | Update trigger | Database update triggers Realtime notification |
| Editor | Text parsing | Frontend regex must match backend page marker format |

### Step 4: Integration Test Execution

**Create Test Script**: `backend/tests/integration/test_full_flow.py`

```python
import pytest
import requests
import time

API_BASE = "http://localhost:8000"
FRONTEND_BASE = "http://localhost:5173"

def test_scenario_1_small_pdf():
    """Scenario 1: Small PDF (10 pages)"""

    # Step 1: Upload PDF
    with open("test-10-pages.pdf", "rb") as f:
        response = requests.post(
            f"{API_BASE}/api/documents/upload",
            files={"file": f}
        )
    assert response.status_code == 200
    doc_id = response.json()["id"]

    # Step 2: Start extraction
    response = requests.post(
        f"{API_BASE}/api/text-extraction/extract-with-batching/{doc_id}",
        json={"auto_translate": False}
    )
    assert response.status_code == 200
    job_id = response.json()["job_id"]

    # Step 3: Poll until complete
    for _ in range(60):  # Max 2 minutes
        response = requests.get(f"{API_BASE}/api/text-extraction/status/{job_id}")
        status = response.json()
        if status["status"] == "completed":
            break
        time.sleep(2)

    assert status["status"] == "completed"
    assert status["progress"] == 100

    # Step 4: Verify page markers
    # (Query Supabase directly to get extracted_text)
    # Verify format: # [Page 1], # [Page 2], etc.
    print("✅ Scenario 1 passed")

def test_scenario_3_selected_pages():
    """Scenario 3: Selected Pages"""

    # Upload
    with open("test.pdf", "rb") as f:
        response = requests.post(f"{API_BASE}/api/documents/upload", files={"file": f})
    doc_id = response.json()["id"]

    # Extract selected pages
    response = requests.post(
        f"{API_BASE}/api/text-extraction/extract-with-batching/{doc_id}",
        json={"selected_pages": [1, 5, 10]}
    )
    job_id = response.json()["job_id"]

    # Wait for completion
    for _ in range(60):
        response = requests.get(f"{API_BASE}/api/text-extraction/status/{job_id}")
        status = response.json()
        if status["status"] == "completed":
            break
        time.sleep(2)

    # Verify only 3 pages
    # Verify page markers are [Page 1], [Page 5], [Page 10]
    print("✅ Scenario 3 passed")
```
