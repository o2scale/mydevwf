# Story 1.1: Supabase Cloud Setup & Direct Database Connection

**Epic**: Epic 1 - Core Translation System
**Priority**: P0 (Blocker)
**Estimate**: 1-2 days
**Status**: Ready for Development

---

## User Story

**As a** Developer
**I want** to establish direct PostgreSQL connection to Supabase (NOT via REST API)
**So that** I can use pgmq, run custom SQL, and have full database access from the backend

---

## Problem Statement

Previous attempts at using Supabase were blocked from direct PostgreSQL access and forced to use PostgREST APIs only. This story MUST solve the direct connection problem because:

1. **pgmq requires direct SQL access** - Cannot use pgmq through REST API
2. **Custom queries needed** - Backend needs to execute raw SQL for batch processing
3. **Worker architecture** - Background workers need direct database connection

**Critical Issue**: IPv4/IPv6 networking problems may prevent direct connection. This story must identify and resolve the working connection method.

### Step 2: Test Direct PostgreSQL Connection

**Connection String Formats**:

```bash
# Option 1: Direct connection
postgresql://postgres:[PASSWORD]@db.[PROJECT-REF].supabase.co:5432/postgres

# Option 2: Transaction pooler (recommended for short-lived connections)
postgresql://postgres:[PASSWORD]@[PROJECT-REF].pooler.supabase.com:6543/postgres?pgbouncer=true

# Option 3: Session pooler (recommended for long-lived connections, pgmq compatible)
postgresql://postgres.[PROJECT-REF]:[PASSWORD]@aws-0-[REGION].pooler.supabase.com:5432/postgres
```

**Test Each Method**:

```python
# test_connection.py
import psycopg2
from psycopg2 import sql

connection_strings = [
    "postgresql://postgres:[PASSWORD]@db.[PROJECT-REF].supabase.co:5432/postgres",
    "postgresql://postgres:[PASSWORD]@[PROJECT-REF].pooler.supabase.com:6543/postgres?pgbouncer=true",
    "postgresql://postgres.[PROJECT-REF]:[PASSWORD]@aws-0-[REGION].pooler.supabase.com:5432/postgres"
]

for i, conn_str in enumerate(connection_strings, 1):
    print(f"\nTesting connection method {i}...")
    try:
        conn = psycopg2.connect(conn_str)
        cursor = conn.cursor()

        # Test query
        cursor.execute("SELECT version();")
        version = cursor.fetchone()[0]
        print(f"✅ Connected successfully!")
        print(f"   PostgreSQL version: {version[:50]}...")

        # Test raw SQL execution
        cursor.execute("SELECT NOW();")
        timestamp = cursor.fetchone()[0]
        print(f"   Current time: {timestamp}")

        cursor.close()
        conn.close()

        print(f"✅ Method {i} WORKS")

    except Exception as e:
        print(f"❌ Method {i} FAILED: {e}")
```

### Step 3: Install pgmq Extension

**Via Supabase SQL Editor**:

1. Go to Supabase Dashboard → SQL Editor
2. Create new query
3. Run:

```sql
-- Enable pgmq extension
CREATE EXTENSION IF NOT EXISTS pgmq CASCADE;

-- Verify installation
SELECT extname, extversion FROM pg_extension WHERE extname = 'pgmq';
```

**Expected Output**:
```
extname | extversion
--------+-----------
pgmq    | 1.4.4
```

**Test pgmq via Direct Connection**:

```python
# test_pgmq.py
import psycopg2

conn = psycopg2.connect("postgresql://postgres:[PASSWORD]@...")
cursor = conn.cursor()

# Create test queue
cursor.execute("SELECT pgmq.create('test_queue');")
conn.commit()
print("✅ Queue created")

# Send message
cursor.execute("""
    SELECT pgmq.send(
        'test_queue',
        '{"message": "Hello from pgmq"}'::jsonb
    );
""")
conn.commit()
msg_id = cursor.fetchone()[0]
print(f"✅ Message sent with ID: {msg_id}")

# Read message
cursor.execute("""
    SELECT * FROM pgmq.read('test_queue', 30, 1);
""")
messages = cursor.fetchall()
print(f"✅ Message read: {messages}")

# Delete message
cursor.execute(f"SELECT pgmq.archive('test_queue', {msg_id});")
conn.commit()
print("✅ Message archived")

# Drop test queue
cursor.execute("SELECT pgmq.drop_queue('test_queue');")
conn.commit()
print("✅ Test queue dropped")

cursor.close()
conn.close()

print("\n🎉 pgmq is working correctly via direct connection!")
```

### Step 4: Create Core Database Schema

**Run Schema Migration**:

```sql
-- Enable required extensions
CREATE EXTENSION IF NOT EXISTS "uuid-ossp";
CREATE EXTENSION IF NOT EXISTS "pgmq";

-- ============================================================================
-- DOCUMENTS TABLE
-- ============================================================================
CREATE TABLE documents (
    id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),

    -- File information
    file_name TEXT NOT NULL,
    original_name TEXT NOT NULL,
    file_extension TEXT,
    mime_type TEXT,
    file_size BIGINT,
    file_hash VARCHAR(64),

    -- Storage reference
    storage_path TEXT NOT NULL,

    -- Processing metadata
    page_count INTEGER,
    status TEXT DEFAULT 'uploaded',

    -- Language settings
    source_language TEXT,
    target_language TEXT,

    -- Multi-tenancy
    tenant_id UUID NOT NULL,
    user_id TEXT DEFAULT 'anonymous-user',

    -- Additional metadata
    metadata JSONB,

    -- Timestamps
    created_at TIMESTAMPTZ DEFAULT NOW(),
    updated_at TIMESTAMPTZ DEFAULT NOW(),

    -- Constraints
    CONSTRAINT unique_file_hash UNIQUE (file_hash)
);

-- Indexes
CREATE INDEX idx_documents_tenant_id ON documents(tenant_id);
CREATE INDEX idx_documents_status ON documents(status);
CREATE INDEX idx_documents_created_at ON documents(created_at DESC);

-- ============================================================================
-- TEXT_EXTRACTION_RESULTS TABLE
-- ============================================================================
CREATE TABLE text_extraction_results (
    id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),

    -- Document reference
    document_id UUID NOT NULL REFERENCES documents(id) ON DELETE CASCADE,

    -- Job status
    status TEXT DEFAULT 'queued',
    progress INTEGER DEFAULT 0,

    -- Service information
    service_used TEXT,
    model_version TEXT,

    -- Extraction results
    extracted_text TEXT,
    confidence_score NUMERIC(5,2),

    -- Processing metadata
    page_count INTEGER,
    token_count INTEGER,
    processing_time INTEGER,
    batch_info JSONB,

    -- Selected pages
    selected_pages INTEGER[],

    -- Error handling
    error_message TEXT,
    retry_count INTEGER DEFAULT 0,

    -- Timestamps
    created_at TIMESTAMPTZ DEFAULT NOW(),
    updated_at TIMESTAMPTZ DEFAULT NOW(),
    completed_at TIMESTAMPTZ,

    -- Quality metrics
    low_confidence_pages INTEGER[],
    quality_metadata JSONB
);

CREATE INDEX idx_extraction_document_id ON text_extraction_results(document_id);
CREATE INDEX idx_extraction_status ON text_extraction_results(status);

-- ============================================================================
-- TRANSLATIONS TABLE
-- ============================================================================
CREATE TABLE translations (
    id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),

    -- Document reference
    document_id UUID NOT NULL REFERENCES documents(id) ON DELETE CASCADE,
    source_extraction_id UUID REFERENCES text_extraction_results(id) ON DELETE SET NULL,

    -- Language settings
    target_language TEXT NOT NULL,
    source_language TEXT,

    -- Job status
    status TEXT DEFAULT 'queued',
    progress INTEGER DEFAULT 0,
    queue_position INTEGER,

    -- Service information
    service_used TEXT,
    model_version TEXT,

    -- Translation results
    translated_text TEXT,
    confidence_score NUMERIC(5,2),

    -- Processing metadata
    token_count INTEGER,
    processing_time INTEGER,
    batch_info JSONB,

    -- Selected pages
    selected_pages INTEGER[],

    -- Error handling
    error_message TEXT,
    retry_count INTEGER DEFAULT 0,

    -- Timestamps
    created_at TIMESTAMPTZ DEFAULT NOW(),
    updated_at TIMESTAMPTZ DEFAULT NOW(),
    completed_at TIMESTAMPTZ,

    -- Quality metrics
    quality_metadata JSONB
);

CREATE INDEX idx_translations_document_id ON translations(document_id);
CREATE INDEX idx_translations_status ON translations(status);

-- ============================================================================
-- PROCESSING_BATCHES TABLE
-- ============================================================================
CREATE TABLE processing_batches (
    id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),

    -- References
    document_id UUID NOT NULL REFERENCES documents(id) ON DELETE CASCADE,
    extraction_job_id UUID REFERENCES text_extraction_results(id) ON DELETE CASCADE,

    -- Batch information
    batch_number INTEGER NOT NULL,
    total_batches INTEGER NOT NULL,

    -- Page range
    start_page INTEGER NOT NULL,
    end_page INTEGER NOT NULL,
    page_count INTEGER NOT NULL,

    -- Token estimation
    estimated_tokens INTEGER,
    actual_tokens INTEGER,

    -- Status
    status TEXT DEFAULT 'pending',

    -- Results
    extracted_text TEXT,
    confidence_score NUMERIC(5,2),

    -- Processing metadata
    processing_time INTEGER,
    error_message TEXT,
    retry_count INTEGER DEFAULT 0,

    -- Timestamps
    created_at TIMESTAMPTZ DEFAULT NOW(),
    updated_at TIMESTAMPTZ DEFAULT NOW(),
    completed_at TIMESTAMPTZ,

    -- Constraints
    CONSTRAINT unique_extraction_batch UNIQUE (extraction_job_id, batch_number)
);

CREATE INDEX idx_batches_extraction_job ON processing_batches(extraction_job_id);
CREATE INDEX idx_batches_status ON processing_batches(status);

-- ============================================================================
-- AUTO-UPDATE TRIGGERS
-- ============================================================================
CREATE OR REPLACE FUNCTION update_updated_at_column()
RETURNS TRIGGER AS $$
BEGIN
    NEW.updated_at = NOW();
    RETURN NEW;
END;
$$ LANGUAGE plpgsql;

CREATE TRIGGER update_documents_updated_at
    BEFORE UPDATE ON documents
    FOR EACH ROW
    EXECUTE FUNCTION update_updated_at_column();

CREATE TRIGGER update_text_extraction_results_updated_at
    BEFORE UPDATE ON text_extraction_results
    FOR EACH ROW
    EXECUTE FUNCTION update_updated_at_column();

CREATE TRIGGER update_translations_updated_at
    BEFORE UPDATE ON translations
    FOR EACH ROW
    EXECUTE FUNCTION update_updated_at_column();

CREATE TRIGGER update_processing_batches_updated_at
    BEFORE UPDATE ON processing_batches
    FOR EACH ROW
    EXECUTE FUNCTION update_updated_at_column();
```

### Step 7: Create Health Check Endpoint

**Create `backend/api/main.py`**:

```python
from fastapi import FastAPI
from fastapi.middleware.cors import CORSMiddleware
import psycopg2
import os
from dotenv import load_dotenv

load_dotenv()

app = FastAPI(title="HDA Translation Platform API", version="2.0.0")

# CORS configuration
app.add_middleware(
    CORSMiddleware,
    allow_origins=os.getenv("CORS_ORIGINS", "").split(","),
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)

@app.get("/health")
async def health_check():
    """Health check endpoint with database connection test"""

    try:
        # Test database connection
        conn = psycopg2.connect(os.getenv("DATABASE_URL"))
        cursor = conn.cursor()

        # Test query
        cursor.execute("SELECT NOW();")
        db_time = cursor.fetchone()[0]

        # Test pgmq
        cursor.execute("SELECT COUNT(*) FROM pgmq.list_queues();")
        queue_count = cursor.fetchone()[0]

        cursor.close()
        conn.close()

        return {
            "status": "healthy",
            "database": "connected",
            "pgmq_queues": queue_count,
            "db_time": str(db_time)
        }

    except Exception as e:
        return {
            "status": "unhealthy",
            "error": str(e)
        }

@app.get("/")
async def root():
    return {
        "message": "HDA Translation Platform API v2.0",
        "docs": "/docs",
        "health": "/health"
    }
```
