## User Story

**As a** Content Reviewer / Quality Assurance Lead
**I want** to review and approve/reject text extractions and translations before they are marked as complete
**So that** only verified, high-quality content is published and used for downstream workflows

**As a** User managing multiple translations
**I want** to filter translations by language and see per-language status
**So that** I can efficiently track and review translations in specific languages

---

## Context

**Queue Architecture**:
- 🔄 **Two Separate Queues** (pgmq-based):
  1. **`text_extraction_queue`** - Jobs for extracting text from PDFs
  2. **`translation_queue`** - Jobs for translating extracted text to target languages
- Each queue operates independently with its own workers
- Jobs cannot be in both queues simultaneously
- Clear separation: Extract → Review → Translate → Review

**Current State**:
- ✅ Text extraction completes → immediately marked "completed"
- ✅ Translation completes → immediately marked "completed"
- ✅ Two separate queues exist (`text_extraction_queue`, `translation_queue`)
- ❌ No human review/verification step
- ❌ No per-language status tracking
- ❌ No language filtering in queue
- ❌ No way to approve/reject individual languages

**Desired State**:
- Text extraction completes → **"in_review"** → human approves → "completed"
- Translation completes → **"in_review"** (per language) → human approves each language → "completed"
- Queue page has **language filter** (show only Hindi translations, only Bengali, etc.)
- Editor has **language toggle** (switch between Hindi/Bengali/Tamil translations)
- Per-language review actions (approve Hindi, reject Bengali, etc.)
- Granular tracking: Each language has own status (processing, in_review, completed, failed)

**Business Value**:
- **Quality Assurance**: Human verification prevents poor OCR/translation from reaching users
- **Compliance**: Legal/religious content requires expert review before publication
- **Efficiency**: Reviewers can filter by language, review only their expertise area
- **Auditability**: Track who approved what, when, with notes

**Use Cases**:
1. **Text Extraction Review**: Reviewer compares extracted text to PDF, approves if accurate
2. **Translation Review**: Hindi expert reviews only Hindi translations, approves/rejects
3. **Language Filtering**: Project manager checks status of all Bengali translations across documents
4. **Partial Approval**: 3/4 languages approved, 1 needs re-translation, others can proceed
5. **Rejection Workflow**: Reviewer rejects poor translation with notes, worker re-processes

## Queue Architecture Deep Dive

### Two Independent Queues (pgmq)

**Queue 1: `text_extraction_queue`**
- Purpose: Process PDF text extraction jobs
- Worker Pool: `backend/workers/worker_pool.py` (24 workers)
- Job Format:
  ```json
  {
    "job_id": "uuid",
    "document_id": "uuid",
    "selected_pages": [1, 2, 3],
    "priority": 5
  }
  ```
- Status Flow: `queued → processing → in_review → completed`

**Queue 2: `translation_queue`**
- Purpose: Process translation jobs (per language)
- Worker Pool: `backend/workers/translation_pool.py` (24 workers)
- Job Format:
  ```json
  {
    "job_id": "uuid",
    "document_id": "uuid",
    "target_languages": ["hi"],
    "source_language": "en",
    "priority": 5,
    "process_immediately": false
  }
  ```
- Status Flow: `queued → processing → in_review → completed`

**Key Points**:
- Jobs NEVER exist in both queues simultaneously
- Clear transition: Extract (queue 1) → Review → Translate (queue 2) → Review
- Each queue has independent priority system
- Queue page filter shows jobs from selected queue

### Job Lifecycle Across Both Queues

```
1. User uploads PDF
   └─> Document created in database

2. Text extraction job created
   └─> Added to text_extraction_queue (Queue 1)
       Status: queued

3. Text extraction worker processes
   └─> Status: processing
       Worker downloads PDF, calls Vertex AI

4. Extraction completes
   └─> Status: in_review
       Job removed from text_extraction_queue
       Reviewer must approve

5. Reviewer approves extraction
   └─> Status: completed
       Text extraction DONE

6. User starts translation (or auto-start)
   └─> Translation job created
       Added to translation_queue (Queue 2)
       Status: queued

7. Translation worker processes
   └─> Status: processing
       Worker translates to each language

8. Translation completes
   └─> Status: in_review
       Job removed from translation_queue
       Reviewer must approve each language

9. Reviewer approves all languages
   └─> Status: completed
       Translation DONE
```

**Critical Rule**: A document can have:
- 1 job in `text_extraction_queue` (active extraction)
- Multiple jobs in `translation_queue` (1 per language if processing separately, OR 1 job for all languages)
- But NEVER the same job in both queues

## State Definitions

### Text Extraction States

| State | Description | Trigger | User Actions |
|-------|-------------|---------|--------------|
| **queued** | Waiting for worker | User uploads document | View position, Cancel |
| **processing** | Worker extracting | Worker picks up job | View progress, Cancel |
| **in_review** | Needs human verification | Extraction completes | Approve, Reject, Edit |
| **completed** | Verified ✅ | Reviewer approves | View text, Start translation |
| **failed** | Extraction error ❌ | Worker error | Retry, Delete |

**Workflow**:
```
Upload → queued → processing → in_review → [Reviewer Approves] → completed
                                        ↓
                                   [Reviewer Rejects]
                                        ↓
                                     queued (re-extract)
```

---

### Translation States (Overall)

| State | Description | Trigger | User Actions |
|-------|-------------|---------|--------------|
| **waiting** | Extraction not done | Upload with auto-translate | - |
| **queued** | Waiting for worker | Extraction approved | View position, Cancel |
| **processing** | Translating N languages | Worker picks up job | View progress per language |
| **in_review** | All languages need review | All translations done | Review each language |
| **partial** | Some approved, some pending | Mixed language states | Review pending, Retry failed |
| **completed** | All languages approved ✅ | All languages reviewed | View, Download |
| **failed** | All languages failed ❌ | Worker error | Retry all |

```sql
-- Helper function to calculate overall status
CREATE OR REPLACE FUNCTION calculate_translation_status(lang_status JSONB)
RETURNS VARCHAR AS $$
DECLARE
    total_langs INTEGER;
    completed_langs INTEGER;
    failed_langs INTEGER;
BEGIN
    total_langs := jsonb_object_keys(lang_status)::INTEGER;
    completed_langs := (SELECT COUNT(*) FROM jsonb_each(lang_status) WHERE value->>'status' = 'completed')::INTEGER;
    failed_langs := (SELECT COUNT(*) FROM jsonb_each(lang_status) WHERE value->>'status' = 'failed')::INTEGER;

    IF completed_langs = total_langs THEN
        RETURN 'completed';
    ELSIF failed_langs = total_langs THEN
        RETURN 'failed';
    ELSIF completed_langs > 0 THEN
        RETURN 'partial';
    ELSE
        RETURN 'processing';
    END IF;
END;
$$ LANGUAGE plpgsql;
```

```python
from pydantic import BaseModel
from typing import Literal

class ReviewRequest(BaseModel):
    action: Literal["approve", "reject", "edit"]
    edited_text: Optional[str] = None
    notes: Optional[str] = None

@router.post("/review/{job_id}")
async def review_extraction(job_id: str, request: ReviewRequest, user_id: str = Header(...)):
    """
    Review text extraction result

    Actions:
    - approve: Mark as completed, allow translation to start
    - reject: Mark as failed, re-queue for extraction with notes
    - edit: Save edited text, mark as completed
    """
    supabase = create_client(os.getenv("SUPABASE_URL"), os.getenv("SUPABASE_SERVICE_KEY"))

    # Get extraction job
    result = supabase.table("text_extraction_results").select("*").eq("id", job_id).execute()
    if not result.data:
        raise HTTPException(status_code=404, detail="Extraction job not found")

    job = result.data[0]

    if job["status"] != "in_review":
        raise HTTPException(status_code=400, detail="Job is not in review status")

    # Handle action
    if request.action == "approve":
        update_data = {
            "status": "completed",
            "review_status": "approved",
            "reviewer_id": user_id,
            "reviewed_at": datetime.utcnow().isoformat(),
            "review_notes": request.notes
        }
    elif request.action == "reject":
        update_data = {
            "status": "queued",  # Re-queue for extraction
            "review_status": "rejected",
            "reviewer_id": user_id,
            "reviewed_at": datetime.utcnow().isoformat(),
            "review_notes": request.notes
        }
        # Re-queue job via pgmq
        conn = psycopg2.connect(os.getenv("DATABASE_URL"))
        cursor = conn.cursor()
        cursor.execute(
            "SELECT pgmq.send(%s, %s::jsonb);",
            ("text_extraction_queue", json.dumps({"job_id": job_id, "document_id": job["document_id"]}))
        )
        conn.commit()
        cursor.close()
        conn.close()
    elif request.action == "edit":
        update_data = {
            "status": "completed",
            "review_status": "approved",
            "reviewer_id": user_id,
            "reviewed_at": datetime.utcnow().isoformat(),
            "review_notes": request.notes or "Edited by reviewer",
            "extracted_text": request.edited_text
        }

    # Update database
    supabase.table("text_extraction_results").update(update_data).eq("id", job_id).execute()

    return {"message": f"Extraction {request.action}d successfully", "job_id": job_id}
```

```python
@router.post("/review/{job_id}/{language_code}")
async def review_translation(
    job_id: str,
    language_code: str,
    request: ReviewRequest,
    user_id: str = Header(...)
):
    """
    Review translation for a specific language

    Actions:
    - approve: Mark language as completed and reviewed
    - reject: Re-queue translation for this language only
    - edit: Save edited translation, mark as completed
    """
    supabase = create_client(os.getenv("SUPABASE_URL"), os.getenv("SUPABASE_SERVICE_KEY"))

    # Get translation job
    result = supabase.table("translation_results").select("*").eq("id", job_id).execute()
    if not result.data:
        raise HTTPException(status_code=404, detail="Translation job not found")

    job = result.data[0]
    language_status = job.get("language_status", {})

    if language_code not in language_status:
        raise HTTPException(status_code=404, detail=f"Language {language_code} not found in translation job")

    # Get current language status
    lang_data = language_status[language_code]

    if lang_data["status"] != "in_review":
        raise HTTPException(status_code=400, detail=f"Language {language_code} is not in review status")

    # Handle action
    if request.action == "approve":
        lang_data["status"] = "completed"
        lang_data["reviewed"] = True
        lang_data["reviewer_id"] = user_id
        lang_data["reviewed_at"] = datetime.utcnow().isoformat()
        lang_data["review_notes"] = request.notes

    elif request.action == "reject":
        lang_data["status"] = "queued"
        lang_data["reviewed"] = False
        lang_data["reviewer_id"] = user_id
        lang_data["reviewed_at"] = datetime.utcnow().isoformat()
        lang_data["review_notes"] = request.notes

        # Re-queue translation for this language only
        conn = psycopg2.connect(os.getenv("DATABASE_URL"))
        cursor = conn.cursor()
        cursor.execute(
            "SELECT pgmq.send(%s, %s::jsonb);",
            ("translation_queue", json.dumps({
                "job_id": job_id,
                "document_id": job["document_id"],
                "target_languages": [language_code],  # Only re-translate this language
                "retry": True
            }))
        )
        conn.commit()
        cursor.close()
        conn.close()

    elif request.action == "edit":
        lang_data["status"] = "completed"
        lang_data["reviewed"] = True
        lang_data["reviewer_id"] = user_id
        lang_data["reviewed_at"] = datetime.utcnow().isoformat()
        lang_data["review_notes"] = request.notes or "Edited by reviewer"

        # Update translation text
        translations = job.get("translations", {})
        translations[language_code] = request.edited_text
        job["translations"] = translations

    # Update language_status
    language_status[language_code] = lang_data

    # Calculate overall status
    all_reviewed = all(lang["reviewed"] for lang in language_status.values())
    any_reviewed = any(lang["reviewed"] for lang in language_status.values())

    if all_reviewed:
        overall_status = "completed"
        overall_review_status = "approved"
    elif any_reviewed:
        overall_status = "partial"
        overall_review_status = "partial"
    else:
        overall_status = "in_review"
        overall_review_status = "pending"

    # Update database
    supabase.table("translation_results").update({
        "language_status": language_status,
        "status": overall_status,
        "overall_review_status": overall_review_status,
        "translations": job.get("translations")
    }).eq("id", job_id).execute()

    return {
        "message": f"{language_code} translation {request.action}d successfully",
        "job_id": job_id,
        "language_code": language_code,
        "overall_status": overall_status
    }


@router.post("/review/{job_id}/approve-all")
async def approve_all_languages(job_id: str, notes: str = "", user_id: str = Header(...)):
    """Bulk approve all languages in translation job"""
    supabase = create_client(os.getenv("SUPABASE_URL"), os.getenv("SUPABASE_SERVICE_KEY"))

    result = supabase.table("translation_results").select("*").eq("id", job_id).execute()
    if not result.data:
        raise HTTPException(status_code=404, detail="Translation job not found")

    job = result.data[0]
    language_status = job.get("language_status", {})

    # Approve all languages
    for lang_code in language_status:
        if language_status[lang_code]["status"] == "in_review":
            language_status[lang_code].update({
                "status": "completed",
                "reviewed": True,
                "reviewer_id": user_id,
                "reviewed_at": datetime.utcnow().isoformat(),
                "review_notes": notes or "Bulk approved"
            })

    # Update database
    supabase.table("translation_results").update({
        "language_status": language_status,
        "status": "completed",
        "overall_review_status": "approved"
    }).eq("id", job_id).execute()

    return {"message": "All languages approved", "job_id": job_id}
```

```tsx
import { useState, useEffect } from 'react';
import { toast } from 'sonner';

export default function ProgressiveEditor({ documentId }) {
  const [selectedLanguage, setSelectedLanguage] = useState<string | null>(null);
  const [translationJob, setTranslationJob] = useState<any>(null);
  const [reviewNotes, setReviewNotes] = useState('');

  // Fetch translation job data
  useEffect(() => {
    fetchTranslationJob(documentId).then(setTranslationJob);
  }, [documentId]);

  async function handleReviewAction(languageCode: string, action: 'approve' | 'reject') {
    try {
      const response = await fetch(
        `/api/translations/review/${translationJob.id}/${languageCode}`,
        {
          method: 'POST',
          headers: { 'Content-Type': 'application/json' },
          body: JSON.stringify({ action, notes: reviewNotes }),
        }
      );

      if (!response.ok) throw new Error('Review action failed');

      toast.success(`${languageCode.toUpperCase()} translation ${action}d`);

      // Refresh translation job data
      const updated = await fetchTranslationJob(documentId);
      setTranslationJob(updated);
      setReviewNotes('');

    } catch (error) {
      toast.error(`Failed to ${action}: ${error.message}`);
    }
  }

  const languageStatus = translationJob?.language_status || {};
  const currentLangData = selectedLanguage ? languageStatus[selectedLanguage] : null;

  return (
    <div className="editor-layout">
      {/* PDF Viewer */}
      <div className="pdf-pane">
        {/* ... existing PDF viewer ... */}
      </div>

      {/* Source Text Pane */}
      <div className="source-pane">
        <h3>Source Text (English)</h3>
        {/* ... existing source text display ... */}
      </div>

      {/* Translation Pane (NEW) */}
      <div className="translation-pane">
        <div className="translation-header">
          <h3>Translation</h3>

          {/* Language Toggle Dropdown */}
          <select
            value={selectedLanguage || ''}
            onChange={(e) => setSelectedLanguage(e.target.value)}
            className="language-selector"
          >
            <option value="">Select language...</option>
            {Object.entries(languageStatus).map(([langCode, langData]) => (
              <option
                key={langCode}
                value={langCode}
                disabled={langData.status === 'processing' || langData.status === 'failed'}
              >
                {getLanguageLabel(langCode, langData)}
              </option>
            ))}
          </select>
        </div>

        {/* Translation Content */}
        {selectedLanguage && currentLangData && (
          <div className="translation-content">
            {/* Status Badge */}
            <div className="status-badge">
              {getLanguageStatusBadge(currentLangData)}
            </div>

            {/* Translation Text */}
            <textarea
              className="translation-text"
              value={translationJob.translations?.[selectedLanguage] || ''}
              readOnly={currentLangData.status !== 'in_review'}
            />

            {/* Review Actions (only if in_review) */}
            {currentLangData.status === 'in_review' && (
              <div className="review-actions">
                <h4>Review {selectedLanguage.toUpperCase()}</h4>

                <textarea
                  placeholder="Review notes (optional)"
                  value={reviewNotes}
                  onChange={(e) => setReviewNotes(e.target.value)}
                  className="review-notes"
                />

                <div className="review-buttons">
                  <button
                    className="btn-approve"
                    onClick={() => handleReviewAction(selectedLanguage, 'approve')}
                  >
                    ✓ Approve {selectedLanguage.toUpperCase()}
                  </button>
                  <button
                    className="btn-reject"
                    onClick={() => handleReviewAction(selectedLanguage, 'reject')}
                  >
                    ✗ Reject {selectedLanguage.toUpperCase()}
                  </button>
                </div>
              </div>
            )}

            {/* Show review info if already reviewed */}
            {currentLangData.reviewed && (
              <div className="review-info">
                <p>✅ Reviewed by {currentLangData.reviewer_id}</p>
                <p>At: {new Date(currentLangData.reviewed_at).toLocaleString()}</p>
                {currentLangData.review_notes && (
                  <p>Notes: {currentLangData.review_notes}</p>
                )}
              </div>
            )}
          </div>
        )}
      </div>
    </div>
  );
}

  const icons = {

    te: 'Telugu',
    kn: 'Kannada',
    ml: 'Malayalam',
  };
```
