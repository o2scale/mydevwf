## Technical Implementation Summary

### 1. Supabase Storage Bucket

**Bucket Created**: `documents` (private)
- **Location**: us-west-1
- **S3 Endpoint**: https://axxqiiszvdtialoxwkul.storage.supabase.co/storage/v1/s3
- **Max File Size**: 500MB
- **Access**: Private (requires service key)
- **RLS**: Disabled for MVP (no auth yet)

### 2. Upload Endpoint

**File**: `backend/api/routers/documents.py`

**Features Implemented**:
1. **File Type Validation**: Only PDF files accepted (application/pdf)
2. **File Size Validation**: Maximum 500MB (524,288,000 bytes)
3. **SHA-256 Hash Calculation**: For deduplication
4. **Duplicate Detection**: Returns existing document if hash matches
5. **Page Count Extraction**: Uses PyPDF2 to count pages
6. **Storage Path Generation**: `{tenant_id}/{timestamp}-{filename}`
7. **Supabase Storage Upload**: File uploaded to documents bucket
8. **Database Record Creation**: Metadata saved to documents table
9. **Error Handling with Rollback**: If DB insert fails, storage file is deleted

**Request Parameters**:
- `file` (required): PDF file to upload
- `source_language` (optional): Source language (default: "en")
- `target_language` (optional): Target language
- `tenant_id` (optional): Tenant ID (auto-generated if not provided)

**Response Format**:
```json
{
  "id": "8d82b22e-9d29-4c7c-8a42-ecb0654544f4",
  "file_name": "1759443122809-test-sample.pdf",
  "original_name": "test-sample.pdf",
  "status": "uploaded",
  "storage_path": "06bc23db-ac4a-4119-8467-d66c78c21acd/1759443122809-test-sample.pdf",
  "page_count": 3,
  "file_size": 1166,
  "message": "Document uploaded successfully"
}
```

### 3. Database Integration

**Table**: `documents`

**Fields Populated**:
- `id`: UUID (auto-generated)
- `file_name`: Timestamp-based unique name
- `original_name`: User's original filename
- `file_extension`: `.pdf`
- `mime_type`: `application/pdf`
- `file_size`: Size in bytes
- `file_hash`: SHA-256 hash
- `storage_path`: Supabase Storage path
- `page_count`: Extracted page count
- `status`: `uploaded`
- `tenant_id`: Auto-generated UUID
- `user_id`: `anonymous-user` (temporary, until auth)
- `source_language`: ISO 639-1 code
- `target_language`: ISO 639-1 code (optional)
- `created_at`: Timestamp (auto)
- `updated_at`: Timestamp (auto)

### 4. Deduplication Logic

**How it works**:
1. Calculate SHA-256 hash of uploaded file
2. Query database for existing document with same hash
3. If found: Return existing document with `status: "duplicate"`
4. If not found: Proceed with upload

**Benefits**:
- Saves storage space
- Prevents duplicate processing
- Maintains referential integrity

## Error Handling

### Implemented Error Cases

1. **Invalid File Type** (400)
   - Rejects non-PDF files
   - Returns clear error message

2. **File Too Large** (413)
   - Checks file size before processing
   - Max: 500MB

3. **Corrupt PDF** (400)
   - PyPDF2 validation
   - Returns error if PDF can't be read

4. **Storage Failure** (500)
   - Catches storage upload errors
   - Returns detailed error message

5. **Database Failure** (500)
   - Catches DB insert errors
   - **Rollback**: Deletes uploaded file from storage
   - Prevents orphaned files

## API Documentation

### Endpoint: `POST /api/documents/upload`

**URL**: `http://localhost:8000/api/documents/upload`

**Method**: POST

**Content-Type**: multipart/form-data

**Parameters**:
| Parameter | Type | Required | Default | Description |
|-----------|------|----------|---------|-------------|
| file | File | Yes | - | PDF file to upload |
| source_language | String | No | "en" | Source language (ISO 639-1) |
| target_language | String | No | null | Target language (ISO 639-1) |
| tenant_id | String | No | auto-generated | Tenant ID (UUID) |

**Success Response (200)**:
```json
{
  "id": "uuid",
  "file_name": "timestamp-filename.pdf",
  "original_name": "original.pdf",
  "status": "uploaded",
  "storage_path": "tenant-id/timestamp-filename.pdf",
  "page_count": 10,
  "file_size": 1024,
  "message": "Document uploaded successfully"
}
```

**Duplicate Response (200)**:
```json
{
  "id": "uuid",
  "file_name": "existing-file.pdf",
  "original_name": "duplicate.pdf",
  "storage_path": "tenant-id/existing-file.pdf",
  "page_count": 10,
  "file_size": 1024,
  "status": "duplicate",
  "message": "Document already exists (duplicate detected)"
}
```

**Error Responses**:
- **400**: Invalid file type or corrupt PDF
- **413**: File size exceeds 500MB
- **500**: Storage or database failure
